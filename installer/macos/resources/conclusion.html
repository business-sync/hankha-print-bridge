The Print Bridge is running

  1. A browser window is now showing a pairing code on this Mac.
  2. On your tablet or phone, open the Hankha app and go to Settings → Printing → Connect.
  3. Point the camera at the code. That connects this computer to your shop.

If the window did not open, go to http://127.0.0.1:9200 in any browser on this Mac.

To remove it later: sudo /usr/local/hankha/print-bridge/uninstall.sh
