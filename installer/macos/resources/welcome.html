Hankha Print Bridge

This installs the small helper the POS terminal needs to print to a network receipt or kitchen printer. A browser cannot open a printer socket itself, so it asks this helper to do it.

The installer will:

  • install the helper into /usr/local/hankha/print-bridge
  • start it automatically whenever this Mac boots
  • make it available to the POS at http://127.0.0.1:9200

Install it on every till that prints — not on one shared computer. A POS page served over https is only allowed to talk to a helper on the same machine.
