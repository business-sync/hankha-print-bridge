# 1.12.1 — the Windows installer registers its task again

**1.12.1 is a drop-in upgrade.** `relay.json` and `printers.json` are kept as they are; an upgraded
bridge does not re-enroll and does not appear twice in the POS. This release changes one thing:
the Windows Setup, which on current Windows 10 and 11 builds has been failing at its last step.

## What was wrong

Setup copied every file, then stopped at **"Registering the startup task..."** with

```
Register-ScheduledTask: The task XML contains a value which is incorrectly formatted or out of range.
(10,42):Duration:P99999999DT23H59M59S
```

and the wizard reported that the bridge "was copied, but could not be started". Nothing was
registered and nothing was running.

The bridge's scheduled task carries a 5-minute heartbeat: Task Scheduler re-runs it every five
minutes, which is a no-op while the bridge is up and brings it back if it was ever killed or
exited cleanly — the two cases restart-on-failure does not cover. "Repeat forever" was written
as the largest span PowerShell can hold, which Windows puts into the task as
`P99999999DT23H59M59S`, a value newer builds of Task Scheduler refuse. They refuse the whole
task, not just the heartbeat, so an optional extra took the entire install down with it. The
same script shipped in 1.3.0 through 1.12.0; whether it ran depended on the Windows build of the
PC, not on the bridge version.

## What changes

- The heartbeat is registered as **Indefinitely** — the same form Task Scheduler writes when you
  pick that in its own dialog — which current Windows builds accept.
- If a build still refuses the heartbeat, the installer says so in a warning and **registers the
  task without it**: start at boot, restart after a crash. An install never fails over the extra
  again; it only fails when the task itself cannot be registered, which is a real error and is
  still shown in full.
- The status page's **Start automatically** button on Windows runs this same script, so it is
  fixed by the same change.

Nothing else changed. The macOS installers are rebuilt under the new number and are otherwise
identical to 1.12.0.
